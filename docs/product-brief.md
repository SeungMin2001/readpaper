# Readpaper 제품 구상 초안

이 문서는 초기 기획 대화에서 합의한 내용을 기록한다. 구현 도구와 운영 방식은 검증 결과에 따라 바꿀 수 있다.

## 목적

영문 AI 논문을 원문으로 읽다가 모르는 단어를 빠르게 확인하고 읽기를 이어갈 수 있는 웹 서비스. 번역은 해당 논문의 주제와 문장 맥락에 맞아야 한다. 관련·인용 논문과 배경 지식을 수집해 근거를 제시하는 질문·답변 기능도 제공한다. 첫 사용자는 프로젝트 작성자이며, 향후 앱스토어 앱 출시도 고려한다.

## 확정한 읽기 경험

- 사용자가 PDF 파일을 직접 업로드한다. 논문의 그림, 표, 수식, 글 배치를 원본에 가깝게 보여준다.
- 첫 버전은 글자를 선택할 수 있는 PDF를 지원한다. 페이지가 이미지인 스캔 PDF의 OCR 지원은 이후에 검토한다.
- PDF 업로드 후 논문 본문을 한 문장으로 요약해 저장한다. 요약과 문헌 수집·검색 색인이 준비되면 원문 읽기 화면으로 이동하고, 용어는 누를 때 번역한다. 준비 중 원문을 먼저 열 수 있다.
- 단어를 누르면 그 자리에 문맥에 맞는 짧은 한국어 뜻 **하나**가 나타난다. 다시 누르면 영어 원문으로 돌아온다. 부가 설명이나 여러 후보 뜻은 기본 화면에 표시하지 않는다.
- 첫 버전에는 사용자가 AI의 번역 뜻을 직접 수정하는 기능을 넣지 않는다.
- `reinforcement learning`처럼 여러 단어가 한 AI 전문 용어를 이루면 하나의 선택 단위로 취급하고, 표현 전체를 번역한다.
- 문장 전체 번역은 제공하지 않는다. 제품의 번역 범위는 클릭한 단어 또는 그 단어가 속한 복합 전문 용어의 짧은 뜻이다.
- 업로드 논문의 본문과 참고문헌에 있는 논문 전체, 선정된 관련·후속 인용 논문의 공개 전문을 수집·청킹·저장해 추가 질문의 근거로 검색한다. 공개 전문을 확보하지 못한 논문은 초록만 또는 서지 정보만 있다는 점을 분명히 표시하고, 전문을 수집한 것으로 가장하지 않는다. 답변에서 사용한 논문·절·페이지를 사용자가 확인할 수 있어야 한다.
- 누른 단어는 자동으로 기록한다. 사용자가 원하는 단어를 직접 추가하거나 기록에서 제거할 수 있다. 단어장에는 해당 논문 제목, 원문 문장, 그 자리의 뜻을 함께 남긴다. 첫 버전의 복습은 단어장 조회이며 퀴즈는 포함하지 않는다.
- 업로드한 PDF 파일은 그림 첨부와 출처 확인을 위해 임시 보관하며 읽던 위치는 저장하지 않는다. 같은 논문을 다시 읽으려면 PDF를 다시 선택해야 한다. 단어장은 복습을 위해 유지한다.
- 분석·번역 결과는 마지막 사용 후 24시간 동안 임시 보관하고 자동 삭제한다. 같은 PDF를 그 안에 다시 선택하면 기존 결과를 재사용할 수 있다. 원본 PDF·수집 PDF·본문·색인도 동일하게 만료한다. 현재 화면은 새로고침 후 파일을 다시 선택해야 하며 읽던 위치는 복원하지 않는다.
- 첫 버전은 프로젝트 작성자만 로그인해 사용한다. 다른 사용자의 가입은 이후에 추가한다.

## 번역과 운영 방향

- 외부 AI 번역 API 대신 공개 가중치 LLM을 Mac mini M4(24GB)에서 직접 서빙한다. 웹/API와 임시 분석 결과·단어장은 클라우드에 둔다. Mac mini와 클라우드는 인증된 전용 연결로 통신하고 모델 포트를 공개 인터넷에 직접 노출하지 않는다.
- 업로드 시 본문을 한 문장 영어 핵심 요약으로 만들고 저장한다. 용어를 누르면 서버가 원문에서 범위를 정한 뒤 요약과 선택 용어만 LLM에 전달한다. 모델은 한국어 뜻만 생성한다. 용어는 클릭 때만 추론하므로 첫 클릭은 추론을 기다린다. 문헌 수집과 임베딩은 초기 로딩에 포함한다. 문장 내부 문맥을 생략하므로 다의어 평가가 필요하다.
- 한국어 뜻만 생성해 출력량을 줄이고 고정된 지시문·요약을 재사용 가능한 입력 접두부로 둔다. 서로 다른 용어는 vLLM에 병렬로 보내고 같은 논문·요약·모델·용어의 중복 요청은 위치가 달라도 캐시를 공유한다. 새 뜻과 저장된 뜻의 지연을 분리해 측정한다.
- 처음 누르는 용어와 새로운 질문·답변에는 Mac mini의 LLM이 필요하다. 이미 만든 용어 뜻은 임시 저장본에서 조회할 수 있다. PDF 원본은 그림 첨부와 출처 확인을 위해 24시간 만료 정책으로 보관한다.
- 업로드 논문이 인용한 논문은 전체 목록을 찾고 각 논문의 전체 본문 확보를 시도한다. 관련·후속 인용 논문은 무한정 늘어날 수 있으므로 최신성·주제 관련도를 기준으로 후보를 선정한다. 이용 가능한 공개 전문을 구조 기반으로 청킹해 저장하고, 임베딩·키워드 검색과 리랭킹을 거쳐 근거로 답한다. 공개 전문을 구할 수 없는 자료는 초록만 사용한다고 표시한다. 단계별 설계는 [RAG 확장 설계](rag-design.md)에 기록한다.
- 웹을 먼저 만들고 Docker로 실행을 재현한다. 클라우드 배포와 이후 Kubernetes 적용 여부를 포트폴리오에서 실측 결과와 함께 설명할 수 있도록 한다.

## 검증할 핵심 위험과 미정 사항

- 2단 편집, 줄바꿈, 수식, PDF 텍스트 추출 결과가 클릭 가능한 단어와 정확히 연결되는지 실제 AI 논문으로 확인한다.
- 전문 용어 범위 인식, 논문 문맥에 맞는 뜻, 반복 용어의 처리 일관성, 클릭 응답 시간을 평가한다.
- PDF 원문이 열리기까지의 요약 준비 시간, 첫 용어 클릭 응답 시간, 캐시된 용어 클릭 응답 시간, Mac mini의 추론 처리량을 각각 측정한다. 사용자가 늘면 새 용어 및 질문 요청의 동시 처리 방식도 필요하다.
- 단어장의 기기 간 동기화 방식, PDF 업로드 처리 중 임시 보관 방식, Mac mini와 클라우드의 전용 연결, 클라우드 서비스와 월 비용 상한은 아직 정하지 않았다.
